# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-28

### Added
- Menu bar panel in the style of macOS Control Center, with Liquid Glass on macOS 26+.
- One-click switching of the active GitHub CLI account (`gh auth switch`).
- Settings window: accounts, general options and about.
- Add accounts through the browser (`gh auth login --web`) and sign out with confirmation.
- Welcome flow that installs the GitHub CLI with Homebrew when it's missing.
- Optional login next to the menu bar icon, notifications and Open at Login.
- English and Portuguese (Brazil) localizations.
- Universal binary (Apple silicon and Intel), signed with Developer ID and notarized.
